One front page that sums up the world's news of Wednesday 18 November 2026: 35 stories from six continents — nine told in full with original drawings, a dotted world map marking where each of the nine happened, a by-the-numbers strip, and 26 more stories listed. Every story happened, or was first reported, on that day; disputed claims are attributed, and the sources are named on the page. The program itself only copies the finished image to the output path, byte for byte.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
